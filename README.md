# Network Ops RJ

Portfólio técnico de laboratórios, estudos e documentação prática em **Redes IP**, **NOC**, **troubleshooting** e **operações de rede**.

Este repositório registra minha evolução prática em redes e telecomunicações, com foco em atividades comuns em ambientes de NOC, suporte técnico N1/N2 e infraestrutura de redes.

---

## Objetivo

Construir um portfólio técnico com evidências práticas de estudo em redes, incluindo:

- Laboratórios no Cisco Packet Tracer
- Troubleshooting de conectividade
- Documentação de incidentes simulados
- Configuração de equipamentos Cisco
- Análise de falhas comuns em ambientes de NOC
- Fundamentos de monitoramento de redes

## Aplicação profissional

Os laboratórios deste repositório simulam situações comuns em ambientes de operação de rede, como:

- Host indisponível
- Gateway incorreto
- VLAN incorreta
- Interface down
- Falha de rota
- Perda de pacote
- Latência alta
- Problemas de conectividade entre redes

O foco não é apenas montar topologias, mas praticar o raciocínio operacional usado em NOC:

1. Identificar o sintoma
2. Validar conectividade
3. Isolar a causa
4. Corrigir a falha
5. Testar novamente
6. Documentar o incidente
